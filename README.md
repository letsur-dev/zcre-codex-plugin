# ZCRE for Codex

ZCRE의 이미지·영상·오디오 도구를 Codex에서 사용하세요.
플러그인이 연결 설정을 제공하므로 Client ID, API 키, 권한 또는 설정 파일을 직접 입력하지 않아도 됩니다.
ZCRE 계정과 로컬 Codex 앱이 필요합니다.

## 설치

Codex 대화에 다음처럼 요청하세요.

> https://github.com/letsur-dev/zcre-codex-plugin 에서 ZCRE 플러그인을 설치해줘.
> 로그인할 수 있게 연결을 열어줘. 파일 업로드나 콘텐츠 생성은 하지 마.

설치 후 Codex의 **설정 → 플러그인 → MCP**에서 **zcre-plugin**의 **인증**을 선택합니다.
열린 브라우저에서 ZCRE 계정으로 로그인하고 조회·업로드·생성 권한에 동의한 뒤 Codex로 돌아옵니다.
플러그인 설치 화면에서 바로 연결을 안내하면 그 안내를 따라도 됩니다.

새 대화에서 다음을 요청해 연결을 확인하세요.

> ZCRE에서 사용 가능한 모델을 보여줘. 새 생성은 하지 마.

이전 맞춤형 MCP `zcre` 연결이 있다면 중복 호출을 피하도록 그 연결을 끄세요.
Client Secret·기본 토큰·헤더 입력은 필요 없습니다. 로그인 창은 한 번에 하나만 열어 주세요.

<details>
<summary>직접 설치하는 방법</summary>

Codex CLI가 설치된 터미널에서 실행합니다.

```sh
codex plugin marketplace add https://github.com/letsur-dev/zcre-codex-plugin
codex plugin add zcre@zcre
```

이후 Codex 앱에서 `zcre-plugin`을 인증합니다.
설치 후 도구가 보이지 않으면 Codex를 완전히 종료하고 새 대화에서 다시 확인하세요.

</details>

## 사용 예시

- “Seedance 2.5 참조 파일을 추가할 창을 열어줘. 자동 업로드나 새 생성은 하지 마.”
- “이 이미지로 영상을 만들고 싶어. 가능한 설정과 예상 크레딧을 먼저 보여줘. 승인 전에는 생성하지 마.”
- “방금 요청의 진행 상태를 확인해줘. 같은 요청을 다시 생성하지 마.”

파일 선택 창에서 직접 선택하고 업로드한 뒤 사용할 작업을 알려 주세요.
생성에는 기존 ZCRE 크레딧을 사용합니다. 모델 조회와 파일 업로드에는 생성 크레딧이 들지 않습니다.

## 연결 문제

- `invalid_client` 또는 `invalid_scope`: URL만 직접 등록한 연결 대신 **ZCRE 플러그인**의 인증을 사용하세요.
- 로그인 창이 열리지 않음: 진행 중인 다른 로그인 작업을 완료하거나 닫은 뒤 다시 인증하세요.
- 도구 목록 또는 업로드 창 오류: Codex를 재시작하고 새 대화에서 다시 시도하세요.
- 이 플러그인은 Codex용입니다. ChatGPT 연결은 [ZCRE MCP 안내](https://www.zcre.co.kr/mcp)를 참고하세요.

## 패키지 구성

이 저장소에는 고객용 플러그인 설정·마켓플레이스 목록·사용 안내만 있습니다.
서버 코드나 비밀 키는 포함하지 않습니다. OAuth Client ID는 공개 식별자이며 비밀 키가 아닙니다.
요청 권한은 ZCRE 조회·업로드·생성과 로그인 유지 네 개로 제한합니다.
Codex 0.154.0에서 공개 저장소 설치와 DEV·PRD 로그인·모델 조회·업로드 창 호출을 검증했습니다.
설치만으로 파일 업로드나 유료 생성이 실행되지는 않습니다.
