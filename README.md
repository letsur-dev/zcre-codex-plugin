# ZCRE for Codex

ZCRE의 이미지·영상·오디오 도구를 Codex에서 사용하세요.
플러그인이 연결 설정을 제공하므로 Client ID, API 키, 권한 또는 설정 파일을 직접 입력하지 않아도 됩니다.
ZCRE 계정과 로컬 Codex 앱이 필요합니다.

## 설치

**1. 플러그인 설치**

Codex 대화에 다음 문장을 보내세요.

> https://github.com/letsur-dev/zcre-codex-plugin 에서 ZCRE 플러그인을 설치해줘. 파일 업로드나 콘텐츠 생성은 하지 마.

**2. 같은 대화에서 로그인 요청**

설치가 완료되면 다음 문장을 보내세요.

> ZCRE 플러그인 로그인을 시작해줘. 로그인과 권한 동의는 내가 직접 할게. 업로드나 생성은 하지 마.

**3. 브라우저에서 로그인·권한 동의**

Codex가 안내한 로그인 링크를 열어 ZCRE 계정으로 로그인합니다.
표시된 계정과 **Codex (ZCRE MCP)**가 요청하는 권한을 확인하고 **Allow**를 누르세요.
도구 확인을 위해 Codex 앱을 완전히 종료한 후 다시 열어주세요.

**4. 기존 대화에서 생성 진행**

기존 Codex 대화로 돌아와 원하는 이미지·영상·오디오 생성을 요청하세요.

> ZCRE의 gpt-image-2로 서울 전경 이미지 생성해줘.

생성에는 ZCRE 크레딧이 사용됩니다.

이전 맞춤형 MCP `zcre` 연결이 있다면 중복 호출을 피하도록 그 연결을 끄세요.
Client Secret·기본 토큰·헤더 입력은 필요 없습니다. 로그인 창은 한 번에 하나만 열어 주세요.

<details>
<summary>직접 설치하는 방법</summary>

Codex CLI가 설치된 터미널에서 실행합니다.

```sh
codex plugin marketplace add https://github.com/letsur-dev/zcre-codex-plugin
codex plugin add zcre@zcre
```

설치가 완료되면 위의 **2. 같은 대화에서 로그인 요청**부터 진행하세요.
설치·로그인 완료와 대화에서 도구 사용 가능 여부는 별개입니다. 생성 없이 연결만 확인하려면 “ZCRE에서 사용 가능한 모델 목록만 보여줘. 업로드나 생성은 하지 마.”라고 요청하세요.

</details>

## 사용 예시

- “Seedance 2.5 참조 파일을 추가할 창을 열어줘. 자동 업로드나 새 생성은 하지 마.”
- “이 이미지로 영상을 만들고 싶어. 가능한 설정과 예상 크레딧을 먼저 보여줘. 승인 전에는 생성하지 마.”
- “방금 요청의 진행 상태를 확인해줘. 같은 요청을 다시 생성하지 마.”

파일 선택 창에서 직접 선택하고 업로드한 뒤 사용할 작업을 알려 주세요.
생성에는 기존 ZCRE 크레딧을 사용합니다. 모델 조회와 파일 업로드에는 생성 크레딧이 들지 않습니다.

## 연결 문제

- `invalid_client` 또는 `invalid_scope`: URL만 직접 등록한 연결 대신 **ZCRE 플러그인**을 설치하고 대화에서 로그인을 요청하세요.
- 로그인 창이 열리지 않음: 진행 중인 다른 로그인 작업을 완료하거나 닫은 뒤 대화에서 로그인을 다시 요청하세요.
- 로그인했는데 도구를 찾지 못함: Codex가 현재 사용할 수 있는 ZCRE 도구를 다시 확인하도록 요청하세요. 실제 모델 조회 전에는 연결이 완료됐다고 판단하지 마세요. 이 패키지가 Codex 앱의 도구 갱신을 강제하지는 않습니다.
- 이 플러그인은 Codex용입니다. ChatGPT 연결은 [ZCRE MCP 안내](https://www.zcre.co.kr/mcp)를 참고하세요.
