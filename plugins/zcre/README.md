# ZCRE for Codex

1. Codex 대화에서 이 저장소의 ZCRE 플러그인 설치를 요청합니다.
2. 설치가 완료되면 같은 대화에서 아래 문장을 보냅니다.

   > ZCRE 플러그인 로그인을 시작해줘. 로그인과 권한 동의는 내가 직접 할게. 업로드나 생성은 하지 마.

3. Codex가 안내한 로그인 링크를 열어 브라우저에서 ZCRE 계정으로 로그인하고, Codex (ZCRE MCP)의 권한을 확인한 뒤 Allow를 누릅니다. 도구 확인을 위해 Codex 앱을 완전히 종료한 후 다시 열어주세요.
4. **기존 대화에서 생성 진행**: 기존 Codex 대화로 돌아와 “ZCRE의 gpt-image-2로 서울 전경 이미지 생성해줘.”처럼 원하는 작업을 요청합니다. 생성에는 ZCRE 크레딧이 사용됩니다.

Client ID, API 키, 헤더 또는 설정 파일을 직접 입력할 필요가 없습니다.
기존에 맞춤형 MCP로 추가한 ZCRE가 있다면 중복 호출을 피하도록 해당 연결을 끄세요.
로그인 창은 한 번에 하나만 열어 주세요. 모델 목록 조회가 성공하면 연결 확인이 끝납니다. 로그인 후에도 도구가 보이지 않으면 현재 대화에서 사용할 수 있는 ZCRE 도구를 다시 확인하세요. 이 플러그인이 앱의 도구 갱신을 강제하지는 않습니다.

## 참조 파일과 생성

“Seedance 2.5 참조 파일을 추가할 창을 열어줘. 자동 업로드나 새 생성은 하지 마.”라고 요청하면 파일 선택 창이 열립니다.
직접 파일을 선택하고 업로드한 뒤, 무엇을 만들지 알려 주세요.
생성 전 예상 크레딧과 입력 조건을 확인하고 승인하세요. 생성에는 기존 ZCRE 크레딧을 사용합니다.
모델 조회와 파일 업로드에는 생성 크레딧이 차감되지 않습니다.
